# Hangman Game

## About the Project
Hangman is a word-guessing game developed using Python. The player must guess a hidden word by suggesting letters one at a time. The goal is to guess the word before running out of lives.

## Features
- Random word selection.
- Hidden word displayed using placeholders.
- Six lives to guess the word.
- Letter-by-letter guessing.
- Automatic win and loss detection.
- ASCII art game logo.

## Technologies Used
- Python
- Random module

## How to Run
1. Clone or download this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder.
4. Run the following command:

`python main.py`

## How to Play
1. The game randomly selects a hidden word.
2. Enter one letter at a time.
3. Correct guesses reveal letters in the word.
4. Incorrect guesses reduce your remaining lives.
5. Guess the entire word before running out of lives to win!
